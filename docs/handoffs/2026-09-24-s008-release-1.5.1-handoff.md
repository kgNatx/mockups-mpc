## Shipped

- **Version list would not collapse.** `toggleVersionList` (`app/templates/gallery.html`) toggled `.open` correctly, but
  no rule hid a `.ver-list` without `.open`, so a list stayed on screen after it was closed. Fix:
  `.ver-list:not(.open) { display: none; }` in `app/static/style.css`.
- **Hover buttons blended into long titles.** `.feed-actions` now shows a raised tray on row hover or focus
  (`--bg-raised` fill, `--border-dim` border). A left box-shadow in the row's own colour (`--row-bg`: surface, hover,
  or active) fades the title out before the tray. The tray's anchor moved 2px so the buttons stay in place. On touch
  screens the title reserve grew from 102px to 106px. A favorited row with no hover still shows only the star, with no tray.
- **Release 1.5.1:** VERSION, server.json (version + image identifier), pyproject.toml, and CHANGELOG `[1.5.1]`;
  GHCR `1.5.1` + `latest` (same digest `sha256:d327c2e1…`); GitHub Release `v1.5.1` (Latest); MCP registry 1.5.1
  (isLatest). The stylesheet cache-bust is now `?v=1.5.1`.
- **Backup deleted:** `data/mockups.db.bak-pre-1.5.0`, removed through `docker exec`, because `data/` is root-owned.
